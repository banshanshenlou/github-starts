# 跨浏览器回归检查清单（WXT 迁移）

## 执行环境

1. 构建命令：
   - `npm run build`
   - `npm run build:firefox`
   - `npm run zip`
   - `npm run zip:firefox`
   - `npm run verify:build`
2. 加载路径：
   - Chrome/Edge：`.output/chrome-mv3`
   - Firefox：`.output/firefox-mv3`

## P0（必须通过）

1. [ ] GitHub 仓库页出现悬浮管理按钮，按钮可拖拽并在刷新后保持位置。
2. [ ] Stars 列表页可打开侧边栏，仓库列表与分组树渲染正常。
3. [ ] 编辑分组/标签/备注后刷新页面，数据仍保留。
4. [ ] 设置页可执行“保存 / 测试 Token / 创建 Gist”，并显示结果状态。
5. [ ] 点击“同步”后状态流转正确（同步中 -> 已同步）。
6. [ ] 制造冲突后可执行“保留远端 / 保留本地”，冲突状态可清除。

## P1（建议通过）

1. [ ] 断网产生待同步操作，恢复网络后自动同步。
2. [ ] 取消 Star 后缓存清理正确，后续同步不出现脏数据回写。
3. [ ] 国际化文案在中英文环境显示完整，无 key 泄漏。
4. [ ] 图标资源（logo 与 settings svg）在三浏览器均正常展示。
5. [ ] 移动端浏览器（如 Quetta）点击仓库页 Star 后可自动弹出编辑弹框；若触发页面重载，重载完成后仍可自动续接弹框。
